## 1. 项目定位

一个**个人学习向**的 A 股分析工具包，目标是把"实时行情查看"与"多 Agent 投研分析"整合到一个可控的本地环境里。

- **使用者**：个人（张旭），本地运行，不对外提供服务。
- **非目标**：不是生产级投顾系统，不提供真实交易、不对接券商、不对外网公开访问。
- **合规底线**：生成的一切评级/目标价/仓位均为**演示与学习用途**，不构成投资建议；工具内必须有醒目免责说明。

## 3. 技术架构

```
浏览器(看板)  ──HTTP静态文件──▶  server.py (本地, 端口8888)
                                      │
                                      └─/api/analyze?code=XXXX──▶ multi_agent_stock_analysis.analyze_to_html()
                                                                            │
                                                  行情数据：腾讯 qt.gtimg.cn / 东方财富 push2 (多层回退)
```

- **前端**：纯静态 HTML + 原生 JS + ECharts（资金流向图）。零构建步骤。
- **本地服务**：`server.py`（标准库 `http.server` + `ThreadingHTTPServer`），零第三方依赖。
- **数据源**：
  - 前端：东方财富公开接口（JSONP/fetch）+ 新浪搜索兜底。
  - 后端：腾讯 `qt.gtimg.cn` / `ifzq` + 东方财富，多重回退（含 GBK 解码处理）。
- **依赖**：后端需 `requests`（可选）+ `tabulate`。

### 启动方式
1. **桌面一键启动（推荐）**：双击 `~/Desktop/Creat tools/股票看板.app` → 自动起服务并 Safari 打开看板（源码 `启动股票看板.applescript`）。
2. 双击 `start-server.bat`（等价于 `python server.py 8888`）。
3. 浏览器打开 `http://localhost:8888/a-stock-dashboard.html`。
4. 直接在命令行运行 `python multi_agent_stock_analysis.py 600519` 也可单独出报告。

> ⚠️ 端口默认 **8888**（`server.py:125` 默认值，`start-server.bat:4` 显式传参）。8765 为本机「知识学习超级助手」占用端口，故避开；如需自定义可传参，如 `python server.py 8799`。
> ⚠️ 本项目需 **Python ≥ 3.10**（代码使用 PEP 604 联合类型，3.9 下 import 即崩，见 P11）。
> ⚠️ "AI 深度分析"功能**必须经本地服务器访问**；若直接用 `file://` 打开 HTML，按钮会提示需通过服务器。

## 4. 数据源与接口稳定性（已知约束）

- 依赖的非官方公开接口可能随时改字段、加 CORS、限频。代码已做多层 fallback，但**不能作为稳定生产工具**。
- 非交易时间（周末/节假日）部分实时数据为空，分析引擎会因"数据采集失败"报错。
